# Expense Tracker

## Project Description
A simple Python application to record and manage daily expenses.

## Features
- Add expenses
- View expenses
- Calculate total expenses
- Display category-wise summaries
- Save expenses to a CSV file
- Load previously saved expenses
- Validate user input

## Technologies Used
- Python
- CSV module

## How to Run
1. Open the project in VS Code.
2. Open Expense_tracker_implementation.py.
3. Run the Python file.
4. Enter an expense category and amount.
5. View the expense summary.

## Data Storage
Expenses are stored in expenses.csv.
